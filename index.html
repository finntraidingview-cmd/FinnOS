1. Die Diagramm-Bibliothek wird beim Öffnen von einem öffentlichen CDN geladen. Dabei werden keine deiner Einträge übertragen — der CDN-Betreiber sieht aber, wie jeder Webserver, deine IP und den Zeitpunkt.
2. Wenn du dieses Dashboard innerhalb von Claude benutzt, geht der Text aus dem Smart-Capture-Feld und von neuen To-Dos an Claude, damit er richtig einsortiert werden kann. Als heruntergeladene Datei passiert das nicht — dort sortiert eine eingebaute Worterkennung.
3. Das gesprochene Briefing nutzt die Sprachausgabe deines Geräts. Es werden bevorzugt lokale Stimmen gewählt; steht keine zur Verfügung, kann dein Browser den Text an seinen Sprachdienst schicken.
